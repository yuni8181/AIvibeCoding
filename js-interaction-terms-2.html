01

아코디언

초급
Accordion 접었다 펼치는 UI

📌 개념: 클릭하면 콘텐츠가 아래로 펼쳐지고 다시 클릭하면 닫히는 UI예요. 악기 아코디언처럼 늘었다 줄었다 해서 이름이 붙었어요.

🎬 어디서 봐요? FAQ 페이지, 설정 메뉴, 모바일 네비게이션

⚙️ 원리: max-height를 0 ↔ 충분히 큰 값으로 CSS transition해요. height는 auto 값에 transition이 안 되기 때문에 max-height를 씁니다!

const btn = document.querySelector('.acc-btn'); btn.addEventListener('click', () => { body.classList.toggle('open'); arrow.classList.toggle('open'); }); /* CSS: height 대신 max-height! */ .acc-body { max-height: 0; } .acc-body.open { max-height: 300px; }
👆 질문을 클릭해보세요
처음엔 낯설지만, 눈에 보이는 결과가 바로 나와서 오히려 재미있어요! HTML과 CSS를 먼저 익히고 나면 JS가 마법처럼 느껴질 거예요. 🌟
정적인 HTML 페이지가 살아 움직이는 웹사이트로 바뀌어요. 사용자가 클릭하고, 스크롤하고, 드래그할 때 반응하는 UI를 만들 수 있어요!
네! <details>/<summary> 태그를 쓰거나, :checked 트릭을 쓰면 JS 없이도 기본 아코디언이 가능해요. 하지만 세밀한 애니메이션은 JS가 더 유리해요.

타이핑 애니메이션

초급
Typewriter Effect 타자기 효과

📌 개념: 텍스트가 한 글자씩 타이핑되는 것처럼 나타나는 효과예요.

🎬 어디서 봐요? 히어로 섹션 타이틀, 챗봇 응답, 개발자 포트폴리오

⚙️ 원리: setInterval로 일정 시간마다 글자를 하나씩 추가해요. 커서는 CSS animation으로 깜빡이도록 만들어요.

const texts = ['디자이너', '개발자']; let i = 0, j = 0; function type() { el.textContent = texts[i].slice(0, j++); if (j > texts[i].length) { setTimeout(erase, 1500); // 잠깐 대기 } else { setTimeout(type, 100); } } function erase() { /* 역방향 지우기 */ }

숫자 카운터 애니메이션

초급
Number Counter 숫자 올라가기

📌 개념: 0부터 목표 숫자까지 빠르게 올라가며 카운팅하는 효과예요. 숫자가 실시간으로 변해서 시선을 끌어요.

🎬 어디서 봐요? 회사 소개 페이지 통계, 대시보드, 게임 점수

⚙️ 원리: requestAnimationFrame으로 매 프레임마다 숫자를 업데이트해요. easeOut 수식으로 처음엔 빠르고 끝엔 느리게!

function countUp(el, target) { let start = 0; const step = () => { start += (target - start) * 0.05; el.textContent = Math.floor(start); if (start < target - 1) { requestAnimationFrame(step); } else { el.textContent = target; // 정확한 값 } }; requestAnimationFrame(step); }

탭 컴포넌트

Tab Component 탭 전환 UI

📌 개념: 탭을 클릭하면 관련 콘텐츠 영역이 전환되는 UI 패턴이에요. 같은 공간에 여러 콘텐츠를 넣을 때 사용해요.

🎬 어디서 봐요? 상품 상세 페이지, 설정 화면, 대시보드, 코드 에디터

⚙️ 원리: 탭 버튼에 active 클래스 토글, 패널은 active일 때만 display:block. CSS animation으로 부드럽게 전환!

tabs.forEach(tab => { tab.addEventListener('click', () => { // 모두 비활성화 tabs.forEach(t => t.classList.remove('active')); panels.forEach(p => p.classList.remove('active')); // 선택된 것만 활성화 tab.classList.add('active'); getPanel(tab) .classList.add('active'); }); });

마그넷 버튼

중급
Magnet Button 자석 버튼

📌 개념: 마우스가 버튼 근처에 오면 자석처럼 끌어당기는 효과예요. 명품 브랜드, 크리에이티브 에이전시 사이트에서 자주 보여요.

🎬 어디서 봐요? 포트폴리오 사이트, 크리에이티브 에이전시, 명품 브랜드

⚙️ 원리: mousemove에서 버튼 중심과 커서 사이의 거리를 계산해서 translate로 버튼을 살짝 이동시켜요.

el.addEventListener('mousemove', e => { const r = el.getBoundingClientRect(); const cx = r.left + r.width/2; const cy = r.top + r.height/2; const dx = e.clientX - cx; const dy = e.clientY - cy; el.style.transform = `translate(${dx * 0.35}px, ${dy * 0.35}px)`; }); el.addEventListener('mouseleave', () => el.style.transform = '');
🧲 버튼 주변에 마우스를 올려보세요
💡 버튼이 마우스를 향해 살짝 기울어져요!

텍스트 스크램블

중급
Text Scramble 글자 섞임 효과

📌 개념: 텍스트가 처음엔 랜덤한 문자들로 깜빡이다가 점차 올바른 글자로 바뀌는 효과예요. 해킹/디지털 느낌을 줘요.

🎬 어디서 봐요? 사이버펑크 스타일 포트폴리오, 게임 UI, 크리에이티브 에이전시

⚙️ 원리: 각 글자를 랜덤 문자로 교체하면서 일정 확률로 원래 글자로 '확정'시켜 나가요.

const chars = '!@#$%^&*アイウエオ'; function scramble(target) { let revealed = new Array(target.length) .fill(false); const interval = setInterval(() => { el.textContent = target .split('') .map((c, i) => revealed[i] ? c : randomChar()) .join(''); // 랜덤하게 하나씩 확정 if (Math.random() > 0.7) { ... } }, 50); }
🔐 버튼을 누르면 글자가 해독돼요

다크모드 토글

초급
Dark Mode Toggle 테마 전환

📌 개념: 버튼 하나로 밝은 테마 ↔ 어두운 테마를 전환하는 기능이에요. 현대 웹의 거의 필수 기능이 되었어요.

🎬 어디서 봐요? 모든 현대 웹사이트 — 구글, 유튜브, 깃허브, 노션 등

⚙️ 원리: CSS 변수(:root)로 색상을 관리하고, body에 클래스를 토글해서 변수값을 한번에 바꿔요. localStorage로 설정을 저장!

/* CSS */ :root { --bg: #fff; --text: #000; } body.dark { --bg: #0a0a0f; --text: #eee; } /* JS */ toggle.addEventListener('click', () => { document.body.classList .toggle('dark'); // 설정 저장 localStorage.setItem('theme', isDark ? 'dark' : 'light'); });

Tooltip 도움말 말풍선

📌 개념: 요소 위에 마우스를 올리면 짧은 설명이 말풍선처럼 나타나는 UI예요.

🎬 어디서 봐요? 아이콘 버튼 설명, 약어 설명, 폼 도움말, 메뉴 단축키

⚙️ 원리: position:absolute로 말풍선 위치 잡기 + :hover 때 opacity 1. ::after 가상요소로 삼각형 꼬리를 만들어요.

/* CSS만으로 구현 가능! */ .has-tooltip { position: relative; } .tooltip { position: absolute; bottom: calc(100% + 8px); opacity: 0; transition: opacity .2s; } .has-tooltip:hover .tooltip { opacity: 1; } /* 삼각형 꼬리 */ .tooltip::after { border-top-color: white; }

마우스 트레일

중급
Mouse Trail 마우스 잔상 효과

📌 개념: 마우스가 움직일 때 뒤에 잔상이나 파티클이 남는 효과예요. 마법 같은 인상을 줄 수 있어요.

🎬 어디서 봐요? 크리에이티브 포트폴리오, 인터랙티브 아트, 게임 UI

⚙️ 원리: mousemove마다 작은 원 요소를 생성하고, CSS animation으로 사라지게 해요. 시간이 지나면 DOM에서 제거!

area.addEventListener('mousemove', e => { const dot = document .createElement('div'); dot.className = 'trail-dot'; const size = Math.random()*10+4; dot.style.cssText = ` width:${size}px; height:${size}px; left:${e.offsetX}px; top:${e.offsetY}px; background: hsl(${hue++},80%,60%); `; area.appendChild(dot); setTimeout(() => dot.remove(), 600); });
✨ 아래 영역에서 마우스를 움직여보세요

무한 스크롤

중급
Infinite Scroll 끝없이 로딩

📌 개념: 스크롤이 바닥에 닿으면 자동으로 새 콘텐츠를 불러오는 기법이에요. 페이지 번호 없이 계속 이어져요.

🎬 어디서 봐요? 인스타그램, 트위터/X, 네이버 뉴스, 유튜브 피드

⚙️ 원리: Intersection Observer로 마지막 아이템이 보이는지 감지 → API 호출 → 새 아이템 DOM에 추가

// 마지막 아이템 감지 const observer = new IntersectionObserver(entries => { if (entries[0].isIntersecting && !isLoading) { loadMore(); // 데이터 추가 로드 } }); // 리스트 맨 끝 감시 observer.observe(lastItem); async function loadMore() { isLoading = true; const data = await fetchAPI(page++); renderItems(data); isLoading = false; }
