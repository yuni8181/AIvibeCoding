01 · 개념

API가 뭐예요? — 식당으로 이해하기

식당에서 손님은 주방에 직접 들어가지 않아요. 점원(메뉴판)에게 주문하면, 점원이 주방에 전달하고 요리를 가져다줍니다. 이 '점원' 역할이 바로 API예요.

🙋

손님 (나의 앱)

"오늘 날씨 알려줘" 라고 요청

➜요청
Request
🧑‍🍳

API (점원)

요청을 받아서 데이터 창고에 전달하고, 결과를 가져옴

➜응답
Response
🗄️

데이터 (주방)

날씨·교통·관광 등 진짜 정보가 쌓인 곳

💡 한 줄 정리 — API는 "내 앱과 데이터 사이를 연결해 주는 약속된 창구"예요. 우리는 주방(데이터)을 만들 필요 없이, 점원(API)에게 부탁만 하면 됩니다.

02 · 요청과 응답 체험

API는 요청하면 데이터로 답해요

버튼을 눌러 직접 'API 호출'을 체험해 봐요. 요청을 보내면 잠깐 기다린 뒤(로딩) 데이터가 도착합니다.

REQUEST 내 앱이 보내는 요청
GET /api/weather
?region=대전&date=today
RESPONSE API가 돌려주는 데이터
버튼을 누르면 여기에 데이터가 도착해요 ✨

💡 실제 데이터는 보통 JSON이라는 형식으로 와요. { "키": "값" } 모양의 이 데이터를 화면에 예쁘게 보여주면 그게 바로 '앱'이 됩니다.

03 · 공공데이터

공공데이터란? — data.go.kr

정부·공공기관이 가진 데이터를 누구나 무료로 쓸 수 있게 열어둔 것이 공공데이터예요. 공공데이터포털(data.go.kr) 한 곳에서 수만 건의 API를 신청해 쓸 수 있습니다.

🆓

무료 · 합법

회원가입 후 '활용 신청'만 하면 누구나 무료로 사용 가능

📊

방대한 양

날씨·교통·의료·관광·환경 등 거의 모든 분야의 실제 데이터

🔑

서비스키 방식

신청하면 '인증키(서비스키)'를 주고, 그 키로 데이터를 불러옴

📌 활용 순서 — ① data.go.kr 가입 → ② 원하는 데이터 검색 → ③ '활용신청' 클릭 → ④ 서비스키 발급 → ⑤ 내 앱에서 호출. (마지막 슬라이드에서 자세히!)

05 · 경진대회 전략

수상하는 작품의 공통점

1

'진짜 불편'에서 출발한다

거창한 기술보다, 실제로 누군가 겪는 문제를 푸는 작품이 점수를 받아요.

2

공공데이터를 분명히 활용한다

"어떤 데이터셋을, 어떻게" 썼는지 명확해야 해요. 1건 이상 활용은 필수 조건인 경우가 많습니다.

3

AI를 더한다

생성형 AI로 추천·요약·대화 기능을 얹으면 가산점. (우리 바이브 코딩 강점!)

4

동작하는 시제품을 보여준다

기획서만이 아니라 실제로 눌리는 화면(프로토타입)이 있으면 설득력이 확 올라가요.

06 · 만드는 순서

바이브 코딩 5단계

STEP 1

화면 그리기

지역 선택 + 결과 카드. HTML로 뼈대부터.

STEP 2

예쁘게 꾸미기

파스텔 색, 둥근 모서리로 CSS 스타일링.

STEP 3

샘플 데이터 연결

가짜 데이터로 먼저 동작 확인 (API 없이도 OK).

STEP 4

상태별 표현

좋음·보통·나쁨을 색·이모지·문구로.

STEP 5

진짜 API 교체

서비스키 넣고 fetch로 실제 데이터 호출.

🍓 핵심 원칙 — "한 번에 완벽하게"가 아니라 작게 만들고 → 확인하고 → 덧붙이기. 가짜 데이터로 화면이 먼저 돌아가게 만든 뒤 진짜 데이터로 바꾸면 훨씬 쉬워요.

06 · 핵심 코드 미리보기

API 호출은 이렇게 생겼어요

어렵지 않아요. "주소로 요청 → 응답을 받아서 → 화면에 뿌리기" 세 줄 흐름이 전부예요.

// ① 공공데이터 API에 요청 보내기 (fetch)
const 서비스키 = "발급받은_나의_키";
const url = `https://apis.data.go.kr/...?serviceKey=${서비스키}&지역=대전`;

const 응답 = await fetch(url);   // 점원에게 주문
const 데이터 = await 응답.json(); // 요리(JSON) 받기

// ② 받은 데이터를 화면에 보여주기
화면.innerHTML = `현재 미세먼지: ${데이터.미세먼지값}`;

💡 처음엔 fetch 부분을 샘플 데이터로 대체해 연습하고, 익숙해지면 진짜 주소로 바꿔요. 샘플 앱 파일에 둘 다 들어 있어요!

07 · 서비스키 발급

진짜 데이터 쓰려면? 서비스키 받기

1

data.go.kr 회원가입 · 로그인

공공데이터포털에 가입해요. (무료)

2

데이터 검색

예: "에어코리아 대기오염정보" 또는 "미세먼지" 검색.

3

'활용신청' 클릭

오픈 API를 골라 활용신청. 보통 자동/즉시 승인돼요.

4

일반 인증키(서비스키) 복사

마이페이지 → 활용 → 인증키 확인 후 코드에 붙여넣기.

⚠️ 주의 — 서비스키는 비밀번호 같은 거예요. 발표·제출 자료에 그대로 노출하지 않도록 조심! 또 일부 API는 브라우저 보안(CORS) 때문에 샘플 데이터로 연습 후 환경을 맞춰줘야 할 수 있어요. (수업에서 같이 해결!)
