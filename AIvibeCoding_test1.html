✅ 정답: HTML — HyperText Markup Language의 약자로 웹 페이지의 뼈대를 만드는 언어예요.
Q02HTML에서 가장 큰 제목을 표시할 때 사용하는 태그는?
✅ 정답: <h1> — h1~h6까지 있고 숫자가 작을수록 더 큰 제목이에요.
Q03HTML에서 다른 페이지로 이동하는 링크를 만들 때 사용하는 태그는?
✅ 정답: <a href=""> — 앵커(Anchor) 태그로 href 속성에 이동할 주소를 적어요.

Q06CSS는 웹 페이지에서 어떤 역할을 하나요?
✅ 정답: 색상, 크기, 배치 등 디자인을 담당한다 — HTML이 뼈대라면 CSS는 옷(스타일)이에요.
Q07CSS에서 요소들을 가로로 나란히 정렬하는 레이아웃 방식은?
✅ 정답: Flexbox (display: flex) — flex를 사용하면 자식 요소들을 가로·세로 자유롭게 배치할 수 있어요.

Q09브라우저가 서버에 "이 페이지 보여줘!"라고 요청할 때 사용하는 프로토콜(통신 규칙)은?
✅ 정답: HTTP — 브라우저(클라이언트)와 서버가 대화하는 규칙이에요. 피자 주문 전화처럼요!
Q10서버에서 데이터를 가져올 때 사용하는 HTTP 메서드는?
✅ 정답: GET — 메뉴판 보기처럼 서버에서 데이터를 읽어올 때 사용해요.
Q11인터넷에서 데이터를 주고받을 때 사용하는 표준 데이터 형식으로, { "key": "value" } 구조를 가진 것은?
✅ 정답: JSON — 택배 상자처럼 데이터를 표준화된 방식으로 포장해서 주고받아요.
Q12Firebase Firestore는 어떤 방식으로 데이터를 저장하나요?
✅ 정답: JSON 형태의 문서로 저장 — 컬렉션 안에 문서가 있고, 문서 안에 데이터(필드)가 있는 구조예요.
Q13O / X 문제: Firebase를 사용하면 서버를 직접 만들지 않아도 데이터를 저장하고 불러올 수 있다.
✅ 정답: O (맞음) — Firebase는 구글이 제공하는 백엔드 서비스예요. 서버 코드 없이도 데이터베이스, 로그인, 호스팅을 사용할 수 있어요.
