패럴렉스 스크롤링

초급
Parallax Scrolling 시차 스크롤

📌 개념: 스크롤할 때 배경과 전경이 서로 다른 속도로 움직여서 입체적인 깊이감을 만드는 기법이에요.

🎬 어디서 봐요? Apple 제품 소개 페이지, Nike 캠페인 사이트, 게임 소개 페이지

⚙️ 원리: scroll 이벤트를 감지해서 각 레이어의 translateY 값을 다르게 변경해요. 배경은 느리게, 전경은 빠르게!

// 스크롤할 때 실행 window.addEventListener('scroll', () => { const y = window.scrollY; bg.style.transform = `translateY(${y * 0.3}px)`; // 느리게 fg.style.transform = `translateY(${y * 0.7}px)`; // 빠르게 });
🎮 슬라이더로 직접 조작해보세요
✨ 패럴렉스 월드

인터섹션 옵저버

중급
Intersection Observer 교차 관찰자

📌 개념: 요소가 화면(뷰포트)에 나타나거나 사라질 때를 감지하는 브라우저 API예요.

🎬 어디서 봐요? 스크롤 애니메이션, 무한 스크롤, 광고 노출 감지

⚙️ 원리: scroll 이벤트 대신 사용해요. 성능이 훨씬 좋고, 요소의 가시성만 콜백으로 알려줘요.

const observer = new IntersectionObserver((entries) => { entries.forEach(entry => { if (entry.isIntersecting) { // 화면에 보임! entry.target.classList .add('visible'); } }); }, { threshold: 0.2 }); // 20% 보일 때 observer.observe(element);
📦 아래로 스크롤 → 요소들이 나타나요
🌟 첫 번째 아이템 — 화면에 보이면 나타나요
🎨 두 번째 아이템 — 슬라이드 인 애니메이션
🚀 세 번째 아이템 — Intersection Observer 사용
💡 네 번째 아이템 — scroll 이벤트보다 성능 좋음
✨ 다섯 번째 아이템 — threshold: 0.5 설정
🎯 여섯 번째 아이템 — 무한 스크롤에도 사용
스크롤해서 관찰해보세요

스크롤 진행률 바

초급
Scroll Progress Bar 읽기 진행률

📌 개념: 현재 페이지에서 얼마나 스크롤했는지를 상단 바로 시각화하는 기법이에요.

🎬 어디서 봐요? 뉴스 기사, 블로그 포스트, 전자책 뷰어

⚙️ 원리: scrollY ÷ (전체높이 - 화면높이) × 100% 로 계산해요

window.addEventListener('scroll', () => { const total = document.body.scrollHeight - window.innerHeight; const progress = (window.scrollY / total) * 100; bar.style.width = progress + '%'; });
👆 이 페이지 상단을 보세요! 보라색 바가 스크롤에 따라 늘어나요
🔝
현재 스크롤: 0%

Drag & Drop 끌어다 놓기

📌 개념: 마우스로 요소를 클릭해서 끌어다가 다른 위치에 놓는 인터랙션이에요.

🎬 어디서 봐요? 트렐로(Kanban), 구글 드라이브, 파일 업로드, 슬라이드 순서 변경

⚙️ 원리: HTML draggable 속성 + dragstart, dragover, drop 이벤트 사용

// 드래그 대상 el.setAttribute('draggable', 'true'); el.addEventListener('dragstart', e => { e.dataTransfer.setData('id', el.id); }); // 드롭 영역 zone.addEventListener('dragover', e => { e.preventDefault(); // 필수! }); zone.addEventListener('drop', e => { const id = e.dataTransfer .getData('id'); zone.appendChild( document.getElementById(id)); });

모달 / 다이얼로그

초급
Modal / Dialog 팝업 레이어

📌 개념: 현재 페이지 위에 레이어로 뜨는 창이에요. 배경이 어두워지고, 사용자가 행동을 취해야만 닫힌다는 특징이 있어요.

🎬 어디서 봐요? 로그인 팝업, 삭제 확인, 이미지 확대, 약관 동의

⚙️ 원리: position:fixed 오버레이 + z-index 높게 설정. CSS transition으로 애니메이션. 배경 클릭 시 닫힘 처리.

// 모달 열기 function openModal() { overlay.classList.add('active'); document.body.style.overflow = 'hidden'; // 스크롤 막기 } // 배경 클릭 시 닫기 overlay.addEventListener('click', e => { if (e.target === overlay) closeModal(); });
👆 버튼을 클릭해서 모달을 열어보세요
💡 모달 vs 팝업: 팝업(popup)은 새 브라우저 창. 모달(modal)은 같은 페이지 위에 뜨는 레이어. 현대 웹은 거의 모달을 사용해요!

토스트 알림

초급
Toast Notification 스낵바 / 알림

📌 개념: 화면 구석에서 잠깐 나타났다가 자동으로 사라지는 알림이에요. 토스트(빵)가 튀어오르는 모양 같다고 해서 이름이 붙었어요.

🎬 어디서 봐요? "저장되었습니다", "복사 완료", "오류 발생" 알림

⚙️ 원리: JS로 동적으로 DOM 요소 생성 → CSS animation → setTimeout으로 제거

function showToast(msg, icon) { const t = document.createElement('div'); t.className = 'toast'; t.innerHTML = `${icon} ${msg}`; container.appendChild(t); // 3초 후 자동 삭제 setTimeout(() => t.remove(), 3000); }
🔔 버튼을 눌러 토스트를 만들어보세요

스티키 요소

Sticky Element 고정 요소

📌 개념: 스크롤해도 화면의 특정 위치에 달라붙어서 고정되는 요소예요.

🎬 어디서 봐요? 상단 네비게이션, 테이블 헤더, 사이드 목차, 고정 버튼

⚙️ 원리: CSS position: sticky + top 값 설정. 부모 요소 안에서만 작동해요!

/* CSS만으로 구현! */ .sticky-header { position: sticky; top: 0; /* 상단 0px에서 고정 */ z-index: 10; background: rgba(0,0,0,0.8); backdrop-filter: blur(10px); } /* position: fixed 와의 차이? fixed = 부모 무시, 항상 뷰포트 기준 sticky = 부모 안에서만 고정 */
📌 스크롤하면 헤더가 상단에 고정돼요
📌 이 헤더는 sticky예요! (스크롤해보세요)

레이지 로딩

중급
Lazy Loading 지연 로딩

📌 개념: 처음에 모든 걸 불러오지 않고, 필요할 때(화면에 보일 때) 로딩하는 기법이에요.

🎬 어디서 봐요? 인스타그램 피드, 유튜브 썸네일, 네이버 블로그

⚙️ 원리: Intersection Observer로 요소 감지 → 뷰포트에 들어오면 src 설정해서 로드. 페이지 초기 로딩 속도가 빨라져요!

// img에 data-src 사용 <img data-src="real-image.jpg"> // Intersection Observer로 감지 const io = new IntersectionObserver( (entries) => { entries.forEach(e => { if (e.isIntersecting) { e.target.src = e.target.dataset.src; io.unobserve(e.target); } }); } ); // HTML img 태그 기본 지원 <img loading="lazy" src="...">
⏳ 버튼을 눌러 순차 로딩을 시뮬레이션해보세요

스크롤 스냅

초급
Scroll Snap 슬라이드 스냅

📌 개념: 스크롤이 특정 지점에 자동으로 딱 맞춰(snap) 멈추게 하는 기법이에요.

🎬 어디서 봐요? 모바일 카드 슬라이더, 온보딩 화면, 풀페이지 스크롤

⚙️ 원리: 순수 CSS로 구현 가능! scroll-snap-type과 scroll-snap-align 속성만 있으면 돼요.

/* 컨테이너에 적용 */ .container { overflow-x: auto; scroll-snap-type: x mandatory; /* mandatory = 반드시 스냅 proximity = 가까우면 스냅 */ } /* 각 아이템에 적용 */ .item { scroll-snap-align: center; /* start / center / end */ flex: 0 0 80%; }
👉 좌우로 스크롤해보세요 — 딱딱 맞춰져요!

Parallax + Scroll Snap 조합으로 멋진 효과를 낼 수 있어요

// 커서 숨기기 body { cursor: none; } // 마우스 따라다니기 document.addEventListener( 'mousemove', e => { dot.style.transform = `translate( ${e.clientX - 4}px, ${e.clientY - 4}px)`; ring.style.transform = `translate( ${e.clientX - 16}px, ${e.clientY - 16}px)`; });
