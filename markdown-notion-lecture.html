Chapter 01

마크다운이란 무엇이고,
왜 써야 할까?

📝
마크다운 (Markdown)
2004년 John Gruber가 만든 경량 마크업 언어. HTML을 직접 쓰지 않아도 간단한 기호로 서식 있는 문서를 만들 수 있습니다.
🌐
어디서 쓰이나?
GitHub, Notion, Velog, Tistory, Discord, Slack, Obsidian… 개발·디자인·콘텐츠 분야 거의 모든 플랫폼에서 마크다운을 지원합니다.
⚡
포트폴리오와의 관계
GitHub README 파일과 노션 페이지 모두 마크다운 기반. 하나를 배우면 두 플랫폼에서 모두 활용 가능합니다.
01

🚀 배우기 쉽고 빠르다

HTML처럼 태그를 외울 필요 없음. #, **, - 같은 기호만으로 서식 완성.

02

📱 어디서나 열리는 .md 파일

메모장, VS Code, GitHub, Notion 어디서든 동일하게 렌더링. 플랫폼에 종속되지 않습니다.

03

💼 취업·포트폴리오 필수 스킬

개발자·UX·데이터 분야 신입 채용 시 GitHub README 작성 능력을 봅니다. 차별화 포인트!

04

🤖 AI 툴과 궁합이 최고

ChatGPT, Claude, Gemini 등 AI가 마크다운으로 답변을 구성함. 마크다운을 알면 AI 결과물을 더 잘 활용할 수 있습니다.

05

🔄 HTML 자동 변환

대부분의 플랫폼이 마크다운 → HTML 자동 변환 제공. 코딩 몰라도 예쁜 문서 완성!

마크다운 vs 일반 텍스트 비교

Chapter 05

플랫폼 비교:
GitHub README vs 노션

항목 GitHub README 노션 (Notion) 추천 용도
마크다운 지원 ✅ 완전 지원 ✅ 대부분 지원 두 곳 모두 마크다운 기본!
공개 URL ✅ 자동 생성 ✅ Publish 기능 이력서에 링크 첨부 가능
이미지/갤러리 ⚡ 제한적 ✅ 갤러리 뷰 작품 포트폴리오 → 노션 추천
코드 강조 ✅ 뛰어남 ⚡ 기본 지원 개발 프로젝트 → GitHub 추천
DB/표 관리 ✗ 정적 표만 ✅ 강력한 DB 프로젝트 목록 관리 → 노션
협업/공유 ✅ Git 협업 ✅ 실시간 협업 팀 작업 → 둘 다 OK
AI 연동 ⚡ GitHub Copilot ✅ Notion AI AI 글쓰기 → 노션 강점
취업 어필도 ✅ 개발직 필수 ✅ 모든 분야 둘 다 만들면 베스트!

오늘의 실습 과제

🖊️ 실습 1 — 노션 포트폴리오 만들기
1
노션에서 새 페이지 생성 → 커버 이미지 + 아이콘 설정
2
H1으로 자기 이름 + H2로 소개, 기술 스택, 프로젝트 섹션 구성
3
/gallery로 갤러리 뷰 DB 생성 → 프로젝트 카드 3개 이상 작성
4
Share → Publish to web 으로 공개 URL 생성 후 제출
5
단축키 최소 5가지 이상 사용해서 작성하기
💻 실습 2 — GitHub README 작성
1
GitHub에서 자기 이름과 동일한 이름의 저장소 생성 (프로필 README용)
2
README.md 파일에 마크다운으로 자기소개 + 기술 스택 뱃지 삽입
3
표를 활용해 수상 경력 / 프로젝트 목록 정리
4
이미지 1개 이상 삽입 (결과물 스크린샷 or 로고)
5
노션 포트폴리오 URL을 README에 링크로 연결
