section 01

토스인앱(앱인토스)이란

토스 앱 안에서, 별도 설치 없이 바로 실행되는 '미니앱(앱인앱)' 서비스예요. 토스라는 슈퍼앱 하나만 있으면 그 안에서 수십, 수백 개의 서비스를 곧바로 쓸 수 있어요.

1

설치가 없어요

앱스토어/플레이스토어에서 따로 다운로드하지 않고, 토스 안에서 검색해 바로 실행해요.

2

가입이 없어요

토스 로그인으로 1초 연동, 토스페이 결제수단을 그대로 써서 회원가입·결제정보 입력이 줄어요.

3

분야가 다양해요

공공서비스, 교통, 쇼핑, 게임, 건강관리 등 이미 다양한 카테고리의 미니앱이 입점해 있어요.

section 02

왜 구글 플레이보다 진입이 쉬울까

NO 계약
별도의 제휴나 계약 절차 없이, 콘솔에서 계정만 만들면 누구나 시작할 수 있어요.
NO 사업자
사업자 등록 없이도 미니앱을 출시할 수 있어요. (단, 결제·정산 관련 기능은 별도)
짧은 심사
앱 등록 검토는 영업일 1~2일, 출시 전 검수는 보통 2~3일로 끝나요.
설치 0
사용자가 앱을 설치할 필요가 없어서, 마케팅 비용 없이 토스 유저에게 바로 노출돼요.

다음 슬라이드부터 각 단계를 자세히 따라가 봅니다.

step 01–02

워크스페이스 만들기 / 멤버 초대

워크스페이스

  • 팀(또는 개인) 프로젝트를 관리하는 공간
  • 사업자(개인) 단위로 1개만 생성 가능
  • 이름은 중복 불가, 나중에 수정 가능
  • 만든 사람에게 자동으로 '대표관리자' 권한 부여

멤버 초대 (선택)

  • '멤버' 메뉴 → '+초대하기'에서 이메일로 초대
  • 관리자: 멤버 관리·설정 변경 등 전체 권한
  • 구성원: 공동 작업은 가능하나 설정 변경 제한
  • 1인 개발이라면 이 단계는 건너뛰어도 돼요
step 03

앱 등록 — 필수 3가지

'앱' 메뉴 → '+등록하기'. 개발이 끝나지 않아도 미리 등록할 수 있고, 항목별로 임시저장하며 채워나갈 수 있어요.

A

앱 이름

토스 앱에 노출되는 이름. 영문명은 15자 이내, 명사형으로. 일반명사 단독 사용은 피해요.

B

appName

intoss:// 스킴에 쓰이는 고유 ID. 등록 후 수정 불가하니 신중하게 정해요.

C

앱 유형

게임 / 비게임 선택. 이후 입력해야 하는 항목이 이 선택에 따라 달라져요.

step 04

기본 정보 + 이미지 규격

채워야 할 정보

  • 부제 — 서비스를 한 줄로 설명
  • 상세 설명 — 사용자가 실제로 보고·누르고·경험하는 흐름
  • 고객센터 이메일 / 연락처
  • 카테고리 — 비게임은 대·중·소분류까지 선택

이미지 규격 (정확히 지켜야 검토 통과)

  • 앱 로고 — 600×600px PNG (투명 배경 불가)
  • 썸네일 — 1932×828px PNG
  • 스크린샷(선택) — 세로형 3장↑(636×1048px) 또는 가로형 1장↑(1504×741px)
step 05

검토 요청 → 검수 → 출시

1단계
필요한 정보를 모두 채운 뒤 '검토 요청하기' 버튼 클릭
2단계
앱 정보 검토 — 영업일 기준 1~2일 소요, 콘솔·이메일로 결과 안내
3단계
개발 완료 후 실제 출시 검수 — 보통 2~3일, 체크리스트 미리 확인하면 반려 없이 통과
4단계
승인 완료 후 콘솔에서 '출시하기' 클릭 → 토스 앱에 바로 노출
보충 설명

사업자 등록은 언제 필요할까

사업자 없이도 OK

개인 개발자도 가입부터 출시까지 그대로 진행할 수 있어요. 기본적인 미니앱 운영에는 사업자 등록이 필요하지 않아요.

사업자가 필요해지는 순간

  • 인앱결제 / 인앱광고 같은 수익화 기능
  • 토스 로그인 연동

필요해지면 국세청 홈택스에서 신청 가능, 보통 3일 안에 발급돼요.
