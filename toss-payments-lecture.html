01 — 개념 이해

왜 토스페이먼츠인가?

결제 시스템을 직접 만들면 카드사 심사, 보안 인증, PG사 계약 등 엄청난 복잡도가 생깁니다. 토스페이먼츠(TossPayments)는 이 모든 걸 대신 처리해주는 PG(Payment Gateway)사입니다.

🧩

간편한 SDK

JavaScript 한 줄로 결제창 호출. 복잡한 카드사 연동 코드 불필요

🧪

테스트 환경

실제 돈 없이 테스트 가능. 개발/운영 키를 분리해서 안전하게 개발

📑

훌륭한 문서

한국어 공식 문서가 매우 잘 되어 있어 국내 개발자 친화적

💳

다양한 결제수단

카드, 토스페이, 계좌이체, 가상계좌, 휴대폰 등 10가지 이상

🔒

PCI-DSS 인증

카드 정보를 직접 다룰 필요 없음. 보안 책임을 토스가 부담

📦

무료 테스트 계정

사업자 없어도 개발용 테스트 키 즉시 발급 가능

02 — 가입 & 키 발급

테스트 키 발급받기

실제 서비스 오픈 전에는 테스트 키만 있으면 모든 기능을 무료로 사용할 수 있습니다. 5분이면 완료!

1

토스페이먼츠 개발자 센터 가입

developers.tosspayments.com → 이메일로 회원가입 (사업자 불필요)

👉 개발자 센터 바로가기 ↗
2

내 개발 정보 → API 키 확인

클라이언트 키와 시크릿 키 두 가지를 확인합니다.

3

테스트 키 vs 운영 키 확인

개발 단계에서는 반드시 test_ck_...로 시작하는 테스트 키를 사용하세요.

4

성공/실패 URL 설정 (선택)

내 개발 정보 → 결제 설정 → 성공/실패 URL을 등록할 수 있습니다.

03 — 결제 흐름

결제는 2단계로 처리된다

토스페이먼츠 결제는 단순히 "버튼 클릭 → 완료"가 아닙니다. 결제 요청과 결제 승인이라는 두 단계를 반드시 거쳐야 합니다.

결제 전체 흐름
👤구매자
결제 클릭
①
💳토스
결제창
② 결제 요청
📱구매자

③ 성공 리다이렉트
🖥️우리 서버
승인 요청
④ 결제 승인
✅결제
완료!
⑤ DB 저장
STEP 1

🛒 결제 요청 (클라이언트)

SDK로 결제창을 띄우고 금액, 주문번호, 상품명을 전달합니다. 구매자가 카드 정보를 입력하고 결제를 완료하면 성공 URL로 이동합니다.

STEP 2

🏦 결제 승인 (서버)

리다이렉트로 받은 paymentKey, orderId, amount를 서버에서 토스 API에 전달해 최종 승인을 받습니다. 이 단계 없이는 결제가 완료되지 않습니다!

⚠️
가장 중요한 포인트!

결제창에서 구매자가 결제를 마쳐도 서버에서 승인 API를 호출하지 않으면 결제가 완료되지 않습니다. 클라이언트만으로는 결제를 완료할 수 없어요. 이게 보안상 핵심입니다.

전달되는 파라미터 이해하기

파라미터설명누가 만드나?
orderId우리가 만드는 주문 고유 ID (UUID 권장)🖥️ 우리 앱
amount결제 금액 (숫자, 원 단위)🖥️ 우리 앱

paymentKey결제 완료 후 토스가 발급하는 고유 키💳 토스페이먼츠

// ① SDK 초기화 — 클라이언트 키 입력 (test_ck_... 사용)
const tossPayments = TossPayments('test_ck_여기에_클라이언트_키_입력');

// ② 결제 객체 생성
const payment = tossPayments.payment({
  customerKey: 'user_고유_ID' // 로그인 사용자라면 UID 입력, 비회원이면 생략
});

// ③ 고유한 주문 ID 생성 (매 결제마다 새로 만들어야 함)
function generateOrderId() {
  return 'order_' + Date.now() + '_' + Math.random().toString(36).slice(2);
}

// ④ 결제 요청 (카드 결제 예시)
async function requestPayment() {
  await payment.requestPayment({
    method: 'CARD',             // 결제 수단
    amount: {
      currency: 'KRW',
      value: 15000,           // 결제 금액 (원)
    },
    orderId: generateOrderId(),  // 고유 주문 ID
    orderName: '테스트 상품 1개',   // 결제창에 표시될 상품명
    successUrl: window.location.origin + '/success',  // 성공 시 이동 URL
    failUrl:    window.location.origin + '/fail',     // 실패 시 이동 URL
    customerEmail: 'buyer@email.com',
    customerName:  '구매자 이름',
    card: {
      useEscrow: false,
      flowMode: 'DEFAULT',   // DEFAULT | DIRECT
    },
  });
}

// 버튼에 이벤트 연결
document.getElementById('pay-btn').addEventListener('click', requestPayment);

05 — 결제 승인

반드시 해야 하는 결제 승인

구매자가 결제를 마치면 successUrl로 이동합니다. URL에 paymentKey, orderId, amount가 쿼리 파라미터로 붙어옵니다. 이걸 받아서 서버에서 승인 처리를 해야 합니다.

성공 페이지에서 파라미터 수신

success.html — 성공 페이지 
const params = new URLSearchParams(window.location.search);

const paymentKey = params.get('paymentKey'); // 토스가 발급한 결제 키
const orderId    = params.get('orderId');    // 우리가 만든 주문 ID
const amount     = params.get('amount');     // 결제 금액

console.log({ paymentKey, orderId, amount });

// 이 세 값을 서버로 전송해서 승인 처리
await confirmPayment({ paymentKey, orderId, amount });

서버에서 결제 승인 API 호출

server.js — Node.js Express 서버 
const express = require('express');
const app     = express();
app.use(express.json());

// 시크릿 키 — .env에 보관 권장!
const SECRET_KEY = 'test_sk_여기에_시크릿_키_입력';

app.post('/confirm', async (req, res) => {
  const { paymentKey, orderId, amount } = req.body;

  // Base64 인코딩 (토스 인증 방식)
  const encoded = Buffer.from(SECRET_KEY + ':').toString('base64');

  try {
    const response = await fetch(
      'https://api.tosspayments.com/v1/payments/confirm',
      {
        method: 'POST',
        headers: {
          'Authorization': `Basic ${encoded}`,
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({ paymentKey, orderId, amount }),
      }
    );

    const data = await response.json();

    if (response.ok) {
      // ✅ 결제 성공 — DB에 저장
      console.log('결제 완료!', data.paymentKey, data.totalAmount);
      res.json({ success: true, data });
    } else {
      // ❌ 결제 실패
      res.status(400).json({ success: false, error: data });
    }
  } catch (err) {
    res.status(500).json({ success: false, error: err.message });
  }
});

app.listen(3000, () => console.log('서버 실행 중 :3000'));
success.js — 학습용 클라이언트 직접 승인 (⚠️ 운영 금지) 
// ⚠️ 학습/테스트 전용 — 실서비스에서는 절대 클라이언트에서 직접 승인 금지!
// 시크릿 키가 노출되어 보안 취약점이 생깁니다.

async function confirmPayment(paymentKey, orderId, amount) {
  const SECRET_KEY = 'test_sk_테스트_키_학습용'; // 테스트 키만!
  const encoded    = btoa(SECRET_KEY + ':');  // Base64 인코딩

  const res = await fetch(
    'https://api.tosspayments.com/v1/payments/confirm',
    {
      method: 'POST',
      headers: {
        'Authorization': `Basic ${encoded}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({ paymentKey, orderId, amount }),
    }
  );

  const data = await res.json();
  console.log(data); // 결제 승인 결과
  return data;
}
functions/index.js — Firebase Cloud Functions 
const functions = require('firebase-functions');
const admin     = require('firebase-admin');
const fetch     = require('node-fetch');
admin.initializeApp();

exports.confirmPayment = functions.https.onCall(async (data) => {
  const { paymentKey, orderId, amount } = data;
  const SECRET_KEY = functions.config().toss.secret_key; // env에서 읽기
  const encoded    = Buffer.from(SECRET_KEY + ':').toString('base64');

  const response = await fetch(
    'https://api.tosspayments.com/v1/payments/confirm',
    {
      method: 'POST',
      headers: { 'Authorization': `Basic ${encoded}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({ paymentKey, orderId, amount }),
    }
  );

  const result = await response.json();

  if (response.ok) {
    // Firestore에 결제 정보 저장
    await admin.firestore().collection('payments').doc(orderId).set({
      paymentKey:  result.paymentKey,
      orderId:     result.orderId,
      amount:      result.totalAmount,
      method:      result.method,
      status:      result.status,
      approvedAt:  result.approvedAt,
      createdAt:   admin.firestore.FieldValue.serverTimestamp(),
    });
    return { success: true, data: result };
  }

  throw new functions.https.HttpsError('internal', result.message);
});

결제 성공 / 실패 응답 처리

✅ 결제 성공 응답

status: "DONE"

응답에 paymentKey, orderId, totalAmount, method, approvedAt 등이 포함됩니다. 이 정보를 DB에 저장합니다.

❌ 결제 실패 응답

failUrl로 이동하며 code, message가 URL 파라미터로 전달됩니다.

흔한 실패 코드: REJECT_CARD_COMPANY, INSUFFICIENT_FUNDS

07 — 체크리스트

빠짐없이 확인하기

⚙️ 개발 환경 설정

  • 토스페이먼츠 개발자 센터 회원가입 완료
  • 테스트 클라이언트 키(test_ck_...) 복사 완료
  • 테스트 시크릿 키(test_sk_...) 복사 완료
  • SDK 스크립트 태그 추가 완료
  • TossPayments(클라이언트키) 초기화 확인

💳 결제 요청 구현

  • orderId 고유값 생성 로직 구현
  • amount 금액 정확히 설정 (숫자 타입)
  • successUrl, failUrl 정확히 설정
  • 결제창이 정상적으로 열리는지 확인
  • 테스트 카드(4242...)로 결제 테스트 완료

✅ 결제 승인 처리

  • successUrl 페이지에서 파라미터 3개 수신 확인
  • 토스 승인 API(v1/payments/confirm) 호출 구현
  • 승인 성공 응답 처리 (DB 저장 또는 화면 표시)

  • 시크릿 키 노출 여부 확인 (클라이언트 코드에 없어야 함)
