01 · API 약자

API — 세 글자가 뭘 뜻하나요?

API는 A·P·I 세 영어 단어의 첫 글자를 딴 약어예요. 각 글자가 무엇을 의미하는지 하나씩 살펴봐요.

AApplication

애플리케이션 — 우리가 만드는 프로그램·앱

여기서 Application은 단순한 모바일 앱만을 뜻하지 않아요. 웹사이트, 스마트폰 앱, 데스크톱 프로그램 등 사용자가 쓰는 모든 소프트웨어를 통칭해요. 우리가 만드는 미세먼지 앱, 버스 도착 앱 모두 Application입니다.

PProgramming

프로그래밍 — 코드로 서로 대화하는 방식

사람끼리는 말로 소통하고, 프로그램끼리는 코드(규칙)로 소통해요. API는 프로그램이 다른 프로그램과 "코드로 대화"할 수 있게 해주는 수단이에요. "이렇게 물어보면 이렇게 대답해줄게"라는 약속된 언어예요.

IInterface

인터페이스 — 서로 다른 것들이 만나는 접점

Interface는 "접점·연결부"예요. USB 포트를 떠올려봐요. 어떤 회사 노트북이든, 어떤 외장하드든 USB 규격만 맞으면 연결되잖아요. API도 마찬가지로 어떤 앱이든 정해진 규칙대로만 요청하면 데이터를 받을 수 있는 표준 연결 포트예요.

✅ 한 문장 정리 — API란 "내가 만드는 앱(A)이 다른 프로그램과 코드로(P) 대화할 수 있게 해주는 표준 연결 창구(I)"입니다.

📤 요청 (Request)이란?

"나 이런 데이터 필요해"라고 API에 보내는 메시지예요.
어느 서버에, 무슨 데이터를, 어떤 조건으로 달라는지를 담아요.
→ 식당에서 주문하는 것

📥 응답 (Response)이란?

API가 요청을 처리하고 돌려보내는 결과물이에요.
보통 JSON이라는 형식으로 데이터가 옵니다.
→ 식당에서 요리가 나오는 것

🔄 이 흐름을 외우면 끝! — 요청(Request) → 처리 → 응답(Response). 모든 API는 이 세 단계로 작동해요. HTTP 통신이라고도 불러요.

01 · API 개념

API가 돌려주는 데이터 형식 — JSON

API에 요청을 보내면 데이터가 JSON 형식으로 와요. JSON이 뭔지, 어떻게 생겼는지 알아야 코드에서 꺼내 쓸 수 있어요.

📋

JSON이란?

JavaScript Object Notation
데이터를 "키:값" 쌍으로 표현하는 공통 데이터 언어예요. 언어·플랫폼 상관없이 어디서나 쓸 수 있어요.

🔑

Key : Value

"이름이 뭐야?" → "대전"
"지역" : "대전"

왼쪽이 키(이름표), 오른쪽이 값(실제 데이터)예요.

📦

{ } 와 [ ]

{ } 중괄호 = 하나의 객체(데이터 묶음)
[ ] 대괄호 = 여러 개의 리스트
공공데이터는 보통 [ { },{ },{ } ] 구조예요.

{  ← 중괄호 : 하나의 데이터 묶음 시작
  "sidoName": "대전",    ← 지역명 (키: 값)
  "stationName": "서구",  ← 측정소 이름
  "pm10Value": "42",     ← 미세먼지 수치 (이걸 꺼내 쓸 거예요!)
  "pm25Value": "18",     ← 초미세먼지 수치
  "dataTime": "2026-06-15 14:00" ← 측정 시각
}                         ← 중괄호 닫기

코드에서 꺼낼 때 → 데이터.pm10Value 이렇게 점(.)으로 키 이름을 연결해서 값을 꺼내요. "대전의 미세먼지 수치 꺼내줘"를 코드로 표현한 거예요.

01 · API 개념

직접 체험: 요청 → 응답 해보기 📡

버튼을 눌러보세요. 실제로 API에 요청을 보내고 데이터가 오는 흐름을 눈으로 확인해요.

REQUEST 내 앱이 보내는 요청
GET https://apis.data.go.kr/
 B552584/ArpltnInforInqireSvc/
 getCtprvnRltmMesureDnsty
?serviceKey=나의인증키
&sidoName=대전
&returnType=json
📍 GET = "데이터 주세요" 방식
📍 주소 = 어느 API 서버로 요청?
📍 ?뒤 파라미터 = 조건 (지역, 인증키 등)
RESPONSE API가 돌려보내는 데이터
버튼을 누르면 여기에
JSON 데이터가 도착해요 ✨
📍 이 JSON에서 pm10Value 꺼내기
📍 코드: data.pm10Value
📍 값 "42"를 화면에 표시하면 → 앱 완성!

🔁 이게 전부예요 — API 사용 = ① 주소로 요청 보내기 → ② JSON으로 데이터 받기 → ③ 원하는 값 꺼내서 화면에 표시. 복잡해 보여도 항상 이 세 단계예요.

02 · 공공데이터

공공데이터 API 주소(URL) 구조 뜯어보기

공공데이터 API를 쓰려면 URL(주소)을 조립해야 해요. 주소가 어떻게 생겼는지 한 파트씩 분석해요.

https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty?serviceKey=발급받은_인증키&returnType=json&numOfRows=100&sidoName=대전&ver=1.0
① 기본 서버 주소
https://apis.data.go.kr
공공데이터포털의 API 서버 주소. 여기까지는 항상 고정이에요.
② API 경로 (어떤 기능?)
B552584/ArpltnInforInqireSvc/
getCtprvnRltmMesureDnsty
에어코리아의 '시도별 실시간 측정정보'. API마다 다르고, 문서에 나와 있어요.
③ serviceKey (필수 인증)
?serviceKey=발급받은_인증키
내가 누군지 증명하는 열쇠. data.go.kr에서 발급받은 키를 넣어요. 없으면 데이터 안 줘요.
④ 파라미터 (조건 지정)
&sidoName=대전
&returnType=json
&numOfRows=100
어느 지역? 어떤 형식으로? 몇 개? — 조건을 지정해요. &로 여러 조건을 이어붙여요.

💡 파라미터는 주문 상세 내용! — 식당에서 "돈가스 주문할게요. 소스는 따로, 밥은 곱빼기로"처럼, 파라미터는 어떤 데이터를, 어떤 조건으로 달라는지 세부 지정이에요.

02 · 공공데이터

서비스키(인증키) 발급받기 — 4단계

공공데이터 API를 쓰려면 먼저 서비스키(인증키)가 있어야 해요. 처음이라도 10분이면 충분해요!

1

🖥️ data.go.kr 접속 → 회원가입

이메일만 있으면 완전 무료로 가입 가능. → www.data.go.kr

2

🔍 원하는 데이터 API 검색

검색창에 "미세먼지" 또는 "에어코리아" 검색 → 상단 탭에서 오픈API 선택하면 API만 모아볼 수 있어요.

3

📋 활용신청 클릭

원하는 API 선택 → [활용신청] 버튼 클릭 → 사용 목적 간단히 입력. 대부분 즉시 자동 승인돼요.

4

🔑 인증키 확인 → 코드에 복사

마이페이지 → 오픈API → 활용신청 현황 → 일반 인증키 복사. 이걸 코드의 serviceKey 자리에 붙여 넣으면 끝!

⚠️ 주의 — 인증키는 비밀번호예요! 발표 화면, GitHub, 유튜브 영상에 키가 그대로 노출되면 다른 사람이 내 이름으로 무한 호출할 수 있어요. 절대 공개 올리지 마세요.

03 · 실제 코드

공공데이터를 코드에 연결하는 전체 흐름

API를 실제로 불러오는 코드는 딱 4단계예요. 각 줄이 무슨 역할인지 주석으로 설명했어요.

// ① 서비스키와 지역 설정
const 서비스키 = "여기에_발급받은_인증키_붙여넣기";
const 지역 = "대전";

// ② API 주소(URL) 조립
//    ? 뒤에 파라미터(조건)를 &로 이어 붙여요
const url =
  "https://apis.data.go.kr/B552584/ArpltnInforInqireSvc/getCtprvnRltmMesureDnsty"
  + "?serviceKey="  + encodeURIComponent(서비스키)
  + "&returnType="  + "json"
  + "&numOfRows="  + 100
  + "&sidoName="   + encodeURIComponent(지역)
  + "&ver="        + "1.0";

// ③ 요청 보내기 (fetch = 점원에게 주문!)
//    async/await 덕분에 데이터가 올 때까지 기다려요
const 응답 = await fetch(url);         // 📡 요청 전송
const json = await 응답.json();         // 📦 JSON으로 변환

// ④ JSON에서 실제 데이터 꺼내기
//    응답 구조: json.response.body.items[0] 가 첫 번째 측정소 데이터
const 측정값 = json.response.body.items[0];

// ⑤ 원하는 값을 꺼내서 화면에 표시!
document.getElementById("결과").innerHTML =
  `미세먼지: ${측정값.pm10Value} ㎍/㎥`;

encodeURIComponent가 뭔가요? — 한글이나 특수문자를 URL에 안전하게 넣어주는 함수예요. "대전"을 그냥 넣으면 서버가 못 읽을 수 있어서, %EB%8C%80%EC%A0%84처럼 인코딩해서 보내요. 그냥 감싸주기만 하면 돼요!

03 · 실제 코드

API 호출이 실패하면? — try/catch

네트워크 문제, 잘못된 키, 서버 오류 등으로 API 호출이 실패할 수 있어요. try/catch로 에러를 잡아두면 앱이 그냥 멈추지 않아요.

async function 미세먼지가져오기() {

  const 서비스키 = "여기에_인증키";
  const url = "https://apis.data.go.kr/.../getCtprvnRltmMesureDnsty"
              + "?serviceKey=" + encodeURIComponent(서비스키)
              + "&sidoName=대전&returnType=json&numOfRows=100&ver=1.0";

  try {
    // 잘 되면 이 블록이 실행돼요
    const 응답 = await fetch(url);
    const json = await 응답.json();
    const 측정값 = json.response.body.items[0];

    document.getElementById("결과").innerHTML =
      `미세먼지: ${측정값.pm10Value} ㎍/㎥`;

  } catch (에러) {
    // 실패하면 이 블록이 실행돼요
    console.log("에러 내용:", 에러);
    document.getElementById("결과").innerHTML =
      "데이터를 가져오지 못했어요 😅 인터넷/키를 확인해주세요";
  }
}

// 버튼에 연결
document.getElementById("버튼").addEventListener("click", 미세먼지가져오기);

❌ 자주 나오는 에러

  • 인증키가 틀렸을 때
  • CORS (브라우저 보안 정책)
  • 승인 전 키 사용

✅ CORS 해결법

  • 서버(Node.js, Firebase) 이용
  • Netlify/Vercel 서버리스 함수
  • 수업에선 샘플 데이터 우선!

💡 디버깅 순서

  • ① F12 → Console 탭 확인
  • ② 에러 메시지 읽기

03 · 실제 코드

샘플 데이터 vs 진짜 API — 코드 비교

수업에서는 샘플 데이터로 먼저 화면을 완성하고, 그 다음 진짜 API로 교체해요. 두 방법의 차이를 코드로 비교해요.

방법 A 샘플 데이터 (연습용)
// API 없이도 화면이 동작해요!
const 샘플 = {
  "대전": { pm10: 42, pm25: 18 },
  "서울": { pm10: 88, pm25: 45 }
};

// 지역 이름으로 바로 꺼내기
const 데이터 = 샘플["대전"];
결과표시(데이터.pm10, 데이터.pm25);
✅ 인터넷 없어도 동작
✅ 서비스키 없어도 OK
✅ 화면 먼저 완성할 때 사용
방법 B 진짜 API (실전용)
// data.go.kr 키 발급 후 교체!
const url = `https://apis.data.go.kr/...`
  + `?serviceKey=${키}`
  + `&sidoName=대전`;

const 응답 = await fetch(url);
const json = await 응답.json();
const 값 = json.response.body
            .items[0];
결과표시(값.pm10Value, 값.pm25Value);
✅ 실시간 실제 데이터
✅ 경진대회 제출용
⚠️ 키 발급 + CORS 해결 필요

🎯 수업 전략 — 먼저 샘플 데이터로 화면을 100% 완성해요. 화면이 예쁘게 나오면, 그때 fetch 코드로 딱 데이터 부분만 교체하면 돼요. 나머지 CSS·HTML은 그대로!

06 · 실습

오늘 실습: 우리동네 미세먼지 알리미 🌫️

지역을 선택하면 미세먼지 상태를 색깔·이모지·수치로 보여주는 앱. 5단계로 함께 만들어봐요.

STEP 1

🏗️ HTML 뼈대

지역 선택 드롭다운 + 조회 버튼 + 결과 카드 영역을 HTML로 만들기

STEP 2

🎨 CSS 꾸미기

파스텔 색·둥근 모서리·폰트. 색상 변수 바꿔서 나만의 디자인!

STEP 3

🎭 샘플 데이터

가짜 데이터로 먼저 화면 동작 확인. 인터넷·API키 없이도 완성!

STEP 4

🎯 상태 표현

수치(pm10)에 따라 색·이모지·문구 다르게. 좋음😄 보통🙂 나쁨😷

STEP 5

🚀 진짜 API

서비스키 발급 후 fetch 코드로 교체. 실시간 데이터 연결!

👉 같이 드린 「미세먼지알리미-샘플앱.html」을 에디터로 열고, 코드 안의 STEP 1~5 주석을 따라가세요. STEP 3까지만 완성해도 경진대회 아이디어 기획 부문 제출 가능, STEP 5까지 완성하면 제품 개발 부문 출품 가능!

실제 코드

fetch → .json() → items[0] → 값 꺼내기 → 화면 표시
